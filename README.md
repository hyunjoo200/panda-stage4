# 중국어 탐험대 · STAGE 02 이름표 마을 (4차시) — 세계의 네 문

4차시 「你是哪国人？」 복습 게임입니다. 문제 12개(종 9개 + 대나무 괴물 3문제), 그중 2개(약 17%)는 2·3차시 복습입니다.
게임 구조(구덩이·계단·움직이는 발판·? 상자·황금 대나무·여러 종류 버섯·순위표·선생님 화면)는 3차시와 같습니다.

| 구역 | 종 | 내용 |
| --- | --- | --- |
| 복습 숲 | 이름 종 | (3차시) 你叫什么名字？ → 我叫小明。 |
| | 연필 종 | (2차시) 谢谢 → 不客气 |
| 국기 마을 | 국기 종 | 韩国·中国·美国·日本을 듣고 국기(1~4번)에 놓기 |
| | 네 문 종 | 我是中国人。을 듣고 1~4번 문 고르기 |
| | 질문 종 | 你 是 哪 国 人 순서대로 놓아 질문 만들기 |
| | 역할 카드 종 | 역할 카드(일본)를 보고 我是日本人。으로 대답 |
| 한자 다리 | 國과 国 종 | 뜻은 같고 모양이 다름 (간체자) |
| | 国 찾기 종 | 国이 없는 나라 이름 찾기 (日本) |
| | 사람 종 | 韩国人의 人 = 사람 |
| 언덕 | 대나무 괴물 | 3인 기자회견 O/X 3문제 (역할 카드 국기와 대답 맞추기) |

국기는 기기마다 이모지가 다르게 보여서 학습용 그림으로 직접 그렸습니다. 국적은 수업처럼 역할 카드로만 다루고, 외모로 국적을 짐작하는 문제는 넣지 않았습니다.
